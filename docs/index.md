# ClubStock

**Club equipment, from request to return.**

ClubStock is a desktop application for managing club equipment on one computer.
It brings Member requests and Exco inventory management together, with both roles
sharing the same local data. Built with Java and JavaFX, it runs on Windows,
macOS, and Linux.

{% if site.screenshot %}
![ClubStock application interface]({{ site.screenshot | relative_url }})
{% endif %}

## What can you do with ClubStock?

- **Members:** browse equipment availability, submit loan requests, track assigned
  items, and report returns, damage, or loss.
- **Exco:** manage member accounts and inventory, approve requests and allocate
  individual items, and verify returns and loss reports.
